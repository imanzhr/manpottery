نسخهٔ اصلاح‌شدهٔ سایت Manpottery

تغییرات:
۱. پاپ‌آپ محصول: عرض کمتر، تصویر کوچک‌تر بدون بریدگی و فاصله‌های جمع‌وجورتر برای نمایش مشخصات. در نمایشگرهای افقی کوتاه، عکس و مشخصات کنار هم قرار می‌گیرند.
۲. هیروی صفحهٔ اصلی در موبایل: تصویر افقی با نسبت ۱۶ به ۱۰. نمایش دسکتاپ حفظ شده است.
۳. منوی همبرگری: همهٔ لینک‌ها و دکمهٔ بستن سفید شده‌اند. پس‌زمینه کمی تیره‌تر شده تا نوشته‌ها روی صفحات روشن نیز خوانا باشند.

استفاده:
این فایل شامل پروژهٔ کامل و پوشهٔ out با خروجی آمادهٔ انتشار است.
برای انتشار روی هاست معمولی، محتویات پوشهٔ out را در پوشهٔ سایت بارگذاری کنید.
برای GitHub Pages، فایل‌های پروژه را جایگزین کنید و اجازه دهید گردش کار موجود خروجی را بسازد. پوشه‌های node_modules و .next لازم نیست بارگذاری شوند.
برای اجرای محلی پروژه:
npm ci
npm run dev
برای ساخت خروجی:
npm run build

بررسی‌ها:
ساخت خروجی، ESLint و TypeScript موفق بودند. وجود فایل‌های تصاویر، اسکریپت‌ها و استایل‌های صفحات خروجی نیز بررسی شد.
آزمایش بصری مرورگر در محیط این گفتگو به علت محدودیت اجرای مرورگر در دسترس نبود.
در نمایشگرهای بسیار کوچک یا با بزرگ‌نمایی زیاد، اسکرول اضطراری حفظ شده است تا اطلاعات حذف یا پنهان نشوند.
